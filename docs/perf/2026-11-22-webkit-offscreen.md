# 画面の外のアニメを止めた効果の計測（#12、headless の WebKit）

`scripts/bench-crowd-webkit.ts` で、全員が作業中（running）の町を測った。生の行は `2026-11-22-webkit-offscreen.jsonl`（label の before と after、r1 と r2 が往復の番号）。

## 条件
- before は PR #148 の親（1068cfd、`src/offscreen.ts` なし）、after は PR #148 のマージ後（80c3789）。どちらも `bun run build` した dist を、同じ script と同じ WebKit（Playwright の webkit-2388）で開いた。
- 窓は幅 1440、deviceScaleFactor 2。15 秒ならしてから、30 秒の CPU 時間（ps の time の差）を1回の起動で2回測った。before、after、before、after の順で2往復し、各場面で1条件あたり4つの値がある。
- 数字は WebContent の CPU 秒（30 秒あたり）。
- 計測は 2026-11-22 の 13:50 から 14:05。この Mac はほかの作業も動いていた。

## 結果

| 場面 | 窓 | カード | 画面内 | before の WebContent | after の WebContent |
| --- | --- | --- | --- | --- | --- |
| A 全員が見えている | 1440×2400 | 20 | 20 | 中央 0.30（0.29〜0.33） | 中央 0.32（0.30〜0.33） |
| B 半分が画面の外 | 1440×900 | 20 | 10 | 中央 0.24（0.18〜0.29） | 中央 0.33（0.31〜0.37） |
| C 画面よりずっと大きい | 1440×900 | 60 | 10 | 中央 0.41（0.37〜0.43） | 中央 0.35（0.26〜0.42） |

場面 B の before は、1往復目が 0.18、2往復目が 0.29 で、往復の間の差が大きい。

## 読み取れること
- 場面 A は差がない。すべて画面内なので止めるものがなく、IntersectionObserver の分の増加も見えない。
- 場面 C は、after の中央が 15% ほど低い。ただし範囲が重なっている（before 0.37〜0.43、after 0.26〜0.42）。効いたと言い切れる数字ではない。
- 場面 B は、after のほうが高く出た。before の1往復目だけが低く、原因は調べていない。
- 画面の外のカードに `data-offscreen` が付いたことは、評価した後の DOM で確認した（場面 C で 50 枚、場面 B で 10 枚）。付くことと CPU が下がることは別で、後者は今回の回数では確かめられていない。
- 足踏み（fc-step）の測定は、この文書の範囲に入れていない。

## 次にやること
- 場面 C と B を、往復を増やして（5往復以上）測り直す。
- WebContent の CPU は 30 秒で 0.3 秒前後と小さく、ほかの負荷の影響を受ける。この Mac が空いているときに測る。
